│ ENTIDAD: training_sessions                                                  │
│ Descripción: Almacena las sesiones de entrenamiento realizadas.              │
│              Cada sesión representa una configuración de lanzamiento         │

│   └─ Identificador único de la sesión.                                      │

│                                                                            │

-- Creación de tablas
CREATE TABLE training_sessions (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    created_at      TEXT NOT NULL,
    player_name     TEXT NOT NULL DEFAULT 'Unknown',
    preset          TEXT,
    duration_seconds INTEGER DEFAULT 0,
    ball_count      INTEGER DEFAULT 0,
    top_motor_speed INTEGER,
    bottom_motor_speed INTEGER,
    horizontal_angle INTEGER,
    launch_interval REAL
);

CREATE TABLE sensor_readings (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id      INTEGER,
    timestamp       TEXT NOT NULL,
    topic           TEXT NOT NULL,
    balls_returned  INTEGER,
    voltage         REAL,
    payload_json    TEXT
);

-- Índices
CREATE INDEX idx_sessions_created ON training_sessions(created_at DESC);
CREATE INDEX idx_sensors_session ON sensor_readings(session_id);
CREATE INDEX idx_sensors_timestamp ON sensor_readings(timestamp DESC);


╔═══════════════════════════════════════════════════════════════════════════════╗
║                       NOTAS ADICIONALES                                      ║
╚═══════════════════════════════════════════════════════════════════════════════╝

• SQLite no soporta FOREIGN KEY de forma obligatoria por defecto
  (PRAGMA foreign_keys = OFF). La integridad referencial se maneja
  desde la capa de aplicación (DatabaseService.deleteSession()
  elimina manualmente las sensor_readings hijas antes de borrar la
  training_session padre).

• Todos los campos de configuración de tiro (top_motor_speed,
  bottom_motor_speed, horizontal_angle, launch_interval) están
  desnormalizados dentro de training_sessions para evitar joins
  innecesarios al mostrar el historial.

• Los timestamps se almacenan como TEXT en formato ISO 8601 por
  compatibilidad multiplataforma en SQLite.

• El campo payload_json en sensor_readings permite almacenar el
  mensaje MQTT completo para depuración futura sin pérdida de datos.

• La sesión_id puede ser NULL porque el sensor puede reportar datos
  incluso cuando no hay una sesión de entrenamiento activa.
